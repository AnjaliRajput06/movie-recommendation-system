# Movie Recommendation System 🎬

A content-based movie recommendation system built using Python, Pandas, and Natural Language Processing (NLP) techniques to suggest movies based on similarity metrics.

## 📌 Features
- Data cleaning and preprocessing on movie metadata.
- Text vectorization using `CountVectorizer` / `TF-IDF`.
- Natural Language Toolkit (`nltk`) integration for stemming and tokenization.
- Cosine similarity calculation to generate personalized recommendations.

## 🛠️ Tech Stack
- **Language:** Python
- **Libraries:** Pandas, NumPy, Scikit-learn, NLTK
- **Environment:** Jupyter Notebook, VS Code
